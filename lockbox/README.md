# lockbox/ — no entrar hasta la fase 5

Contiene la evaluación sobre **2024 → hoy**. Esos datos no se miran, ni se grafican,
ni se usan para calibrar nada, hasta que haya entre 1 y 3 finalistas con parámetros
congelados.

Se ejecuta **una vez**. `.lockbox_used` registra esa ejecución y bloquea las
siguientes. Si ese fichero existe, el resultado del proyecto ya está decidido.
